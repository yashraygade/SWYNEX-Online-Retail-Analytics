# SWYNEX - Online Retail Data Cleaning

## Overview

This project was completed as part of Task 1 of my Data Analyst Internship at SWYNEX Technologies.

The objective was to clean and prepare the UCI Online Retail dataset using Python and Pandas.

## Dataset

UCI Online Retail Dataset

The dataset contains online retail transaction records.

## Data Cleaning Performed

- Checked missing values
- Checked duplicate records
- Checked data types
- Converted date values to datetime format
- Identified cancelled transactions
- Removed cancelled transactions
- Removed invalid quantities
- Removed invalid prices
- Removed duplicate records
- Removed records with missing product descriptions
- Created Revenue column
- Created date-related features
- Performed final data validation

## Tools Used

- Python
- Pandas
- Google Colab
